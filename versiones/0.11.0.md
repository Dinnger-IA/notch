# 0.11.0 · 2026-10-03

- **Hablar manteniendo pulsado**: mantén pulsado el micrófono mientras hablas y suéltalo para enviar. Mientras escucha, la barra se marca en rojo, el micrófono late y te dice «Escuchando… suelta para enviar».
- Para cancelar, aleja el cursor del micrófono antes de soltar («Suelta para cancelar») o pulsa Esc. Un clic corto no graba: te recuerda que hay que mantenerlo pulsado.
- El agente **responde en voz alta solo a lo que le pides hablando**; lo que escribes lo responde por escrito. Se quita la opción «Leer las respuestas en voz alta».
- El botón del altavoz solo aparece mientras el agente habla, para callarlo.

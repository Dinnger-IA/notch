# 0.14.0 · 2026-10-06

- **Citar otro workspace con @**: al escribir `@` en el chat aparece la lista de los demás workspaces abiertos en el notch (flechas para moverte, Intro o Tab para elegir). Con `@nombre` en el mensaje, el agente recibe la ruta de ese proyecto y permiso para leerlo, así puede usarlo como contexto (por ejemplo, «usa el mismo cliente que @api-pagos»).

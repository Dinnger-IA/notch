# 0.20.0 · 2026-11-11

- **Agent Manager pasa a ser lo principal**: Doky es el agente principal en una instalación nueva, y los agentes nuevos de chat y programados usan Agent Manager por defecto (sale el primero en el editor, como *recomendado*). Los CLI (Claude Code, Codex, Gemini) quedan para los agentes de código y en el instalador son opcionales.
- Codex: conectar sus avisos ya no puede dañar `~/.codex/config.toml` cuando la opción `notify` ocupa varias líneas, cuando la ruta del notch lleva un apóstrofo o cuando hay otra opción que empieza por «notify».
- Codex: un turno de la terminal que termina mientras la pestaña está trabajando ya no se pierde; se añade al terminar.
- Codex: los avisos se siguen reenviando a la otra app aunque esté instalada como `.cmd` de npm o `.ps1` (nunca a través de `cmd.exe`, por seguridad).
- Agent Manager: si tu sesión caduca, el notch te pide volver a iniciarla en vez de fallar en cada mensaje; una respuesta que se queda colgada se corta a los 5 minutos; y con Agent Manager desactivado ningún agente le envía nada.
- Adjuntos: solo se suben a Agent Manager los archivos que adjuntaste tú (arrastre o clip), no rutas que aparezcan en un texto pegado.
- Git: funciona en workspaces que son una subcarpeta del repositorio; «Quitar todo» ya no puede dejar preparado el borrado de los archivos; no se confirma con conflictos sin resolver; el doble clic sobre un script lo muestra en el Explorador en vez de ejecutarlo; y una operación colgada (p. ej. un push esperando credenciales) se detiene a los 5 minutos.

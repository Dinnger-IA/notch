# 0.6.0 · 2026-10-03

- **Instalador con Agent Manager**: nueva opción *Usar Agent Manager*. Si la marcas, antes de instalar hay que pulsar **Comprobar conexión**: revisa que el equipo encuentra Agent Manager (red de la empresa o VPN), que responde con un certificado válido y que el puerto del inicio de sesión está libre. Si algo falla, dice el motivo y no deja instalar.
- Si no la marcas, se instala igual y el notch funciona **sin Agent Manager**: no pide iniciar sesión y los agentes usan los CLI del equipo (Claude Code, Codex, Gemini…).
- Instalado sin Agent Manager, se puede activar después desde ⚙ Configuración → *Sesión* → *Usar Agent Manager*.
- Instalación desde un script: con Agent Manager se hace la misma comprobación (si falla, no instala y devuelve el código 3); `--sin-agent-manager` instala sin él.

# 0.7.0 · 2026-10-03

- **Sesiones de Claude Code de tu terminal en el notch**: al abrir un aviso de una sesión que tienes en la terminal, ya no se queda vacío. La sesión aparece en una pestaña de tu agente de código de Claude Code (Codi), con la carpeta del proyecto, lo que pediste, las acciones que hizo y sus respuestas.
- Desde esa pestaña puedes **continuar la misma sesión**: lo que escribas se envía a esa sesión de Claude Code, con las aprobaciones del notch.
- Si no tienes ningún agente de código que use Claude Code, se crea uno llamado **codi-claude**.
- La sesión aparece en cuanto le escribes a Claude Code en la terminal (no hace falta esperar a que termine). Si ya tenías activados los avisos de Claude Code, se actualizan solos.

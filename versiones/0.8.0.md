# 0.8.0 · 2026-10-03

- **El instalador va por etapas**: *Herramientas* → *Opciones* → *Instalación*, con *Atrás* para revisar.
- **Herramientas**: muestra si **Claude Code** y **Codex** están instalados (con su versión) y, si falta alguno, un botón **Instalar** a su lado que lo instala con su método oficial (Claude Code con su instalador de Windows; Codex con npm, e instala antes Node.js con winget si hace falta).
- **Avisos de la terminal**: al instalar se conectan los CLI con el notch (hooks de Claude Code y la opción `notify` de Codex), apuntando al programa instalado. Si Codex ya avisa a otra aplicación (por ejemplo, la app de Codex), no se toca.
- **Sesiones de Codex de la terminal**: cuando una termina, el notch avisa y la muestra en una pestaña de tu agente de código de Codex (o de **codi-codex**, que se crea si no hay ninguno), lista para continuarla.
- La etapa *Instalación* muestra cada paso con su resultado; el notch se abre al final. Desinstalar también quita los avisos de Codex.
- Instalación desde un script: `--instalar-cli` instala los CLI que falten y `--sin-avisos` no conecta los avisos.

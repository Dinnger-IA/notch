# 0.9.0 · 2026-10-03

- **Instalador con Agent Manager por etapas**: *Agent Manager* → *Herramientas* → *Opciones* → *Instalación*. En la primera etapa, si marcas *Usar Agent Manager*, no se puede seguir sin pasar **Comprobar conexión**, y cada fallo dice el motivo.
- En la etapa *Instalación*, con Agent Manager: **iniciar sesión** con tu cuenta (o se reutiliza la sesión guardada) y se añade el **MCP de Agent Manager** a Claude Code y Codex, con el resultado de cada uno.
- Sin Agent Manager se instala igual, y la app funciona solo con los CLI del equipo.
